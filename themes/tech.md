# Theme - Tech

Tech typically features a lot of "Carbon Steel" toned machines, heavy metallic designs and a focus on energy, precision, side effects are generally stated outright and are expected to be tolerable.

## Focus Materials

Tech focuses more on metals, while wood, stone and other "natural" resources are seldom used.

Tech seldom uses mana for anything unless it's explicitly designed to handle mana such as the [Pylon](../devices/pylon.md), even then, tech should be inefficient when directly handling mana.
